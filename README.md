
# Smart OPD — starter MVP

A beginner-friendly hospital OPD registration demo using plain HTML, CSS, and JavaScript. It runs without Node.js or a database.

## Run it

Open `index.html` in a browser. For the best experience, use VS Code's Live Server extension.

## Included

- Responsive hospital landing page
- Four-step, validated OPD registration form
- Department-based doctor choices
- Registration slip and print support
- Local browser storage for registrations
- Status lookup and demo doctor patient table

## Important

This is a front-end learning prototype. Browser local storage is not secure or shared between devices. Before using it for real patient data, replace local storage with an authenticated backend, secure database, validation, access controls, audit logging, and compliant file storage.
